# API Integration Sandbox

Small sandbox project created to practice **API integration and data fetching** using React.

## Purpose

This repository was created to experiment with:

- Fetching data from external APIs
- Logging and inspecting API responses
- Handling asynchronous requests
- Basic React component structure

## Tech Stack

- React
- Vite
- JavaScript (ES6+)

- Example API used: https://wizard-world-api.herokuapp.com/

## How to run

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open the provided localhost URL.

## Notes

This is a **learning sandbox** used to experiment with API integration patterns.
